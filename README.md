# Alexa-Voice-Assistant-Using-Python-and-Machine-Learning
AI Voice Assistant is a Python-based voice assistant that uses OpenAI Whisper for speech-to-text, TF-IDF and MLPClassifier for intent detection, and pyttsx3 for voice responses. It can perform tasks such as web searches, playing music, checking weather, setting simulated alarms, giving directions, calculations, and managing shopping lists.
